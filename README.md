# 江若バス（大石小学校線）時刻表 まとめサイト

石山駅 〜 大石小学校方面の時刻表（平日／土曜日／日祭日 × 上り／下り）を、
GitHub Pages で公開するための静的サイトです。ビルド不要・素のHTML/CSS/JSのみ。

## ファイル構成

```
kojak-bus-timetable/
├─ index.html                トップページ（全体メニュー）
├─ rosenzu.html               路線図ページ
├─ heijitsu-kudari.html       平日 下り
├─ heijitsu-nobori.html       平日 上り
├─ doyo-kudari.html           土曜日 下り
├─ doyo-nobori.html           土曜日 上り
├─ nichisai-kudari.html       日祭日 下り
├─ nichisai-nobori.html       日祭日 上り
├─ assets/
│   ├─ style.css              共通スタイル
│   └─ nav.js                 共通ナビゲーション（各ページが自動で読込）
├─ images/                    時刻表JPG（ここに実ファイルを追加）
├─ pdf/                       印刷用PDF（kojak-timetable.pdf を追加）
├─ LICENSE.md                 著作権・利用条件
└─ README.md                  このファイル
```

画面遷移は `assets/nav.js` が一括管理しています。ページ内に
`window.PAGE_CAT` / `window.PAGE_DIR` を書くだけで、上部の
「下り／上り」タブと「平日／土曜日／日祭日」タブが自動生成されます。
ナビの文言やリンク構造を直したいときは `nav.js` の1ファイルを直せばOKです。

## あなたが追加するファイル

1. `images/` に各時刻表ページのJPGを、`images/README.md` の命名規則どおりに配置
   （例: `heijitsu-kudari-1.jpg`, `rosenzu-1.jpg` など）
2. `pdf/kojak-timetable.pdf` に、路線図1ページ＋時刻表14ページを結合したPDFを配置
   （添付いただいたExcel/PDFをそのままお使いいただけます）

これだけで全ページの画像・ダウンロードリンクが機能します。

## 画像（JPG）の推奨サイズ

紙面はA4横（297×210mm）で、文字が細かい時刻表です。**読みやすさ優先**で、
画面に収まるよう縮小するのではなく「実寸で書き出し、必要なら横スクロールで読む」
設計にしています（HTML側は `img { height: 78vh 前後; width:auto }` で
横スクロールさせています）。

| 用途 | 推奨解像度目安 | 参考ピクセルサイズ（A4横） | JPG品質 | 目安ファイルサイズ |
|---|---|---|---|---|
| 標準（スマホ/PC共通・推奨） | 220〜250 dpi | 約 2550×1800 px | 82〜88% | 500KB〜1.2MB/枚 |
| 高精細（小さい数字も拡大鮮明に） | 300 dpi | 約 3508×2480 px | 80〜85% | 1〜2MB/枚 |
| 軽量重視（通信量を抑えたい場合） | 150 dpi | 約 1754×1240 px | 80% | 200〜400KB/枚 |

**まとめると「2400〜2800px幅・JPG品質85%前後」が汎用的におすすめです。**
これより小さくすると、平日の6分ヘッド区間などの細かい数字が
スマホで潰れて読みにくくなります。逆に300dpiを超えると、14ページ分の
合計サイズが数十MBになりページの初期表示が重くなるため、通常は不要です。

### 書き出し手順の例（Excel → PDF → JPG）

1. Excelの各シートを「印刷範囲＝A4横1ページ」に設定し、シートごとにPDF出力
   （すでにお持ちの14ページ＋路線図1ページのPDFでOK）
2. PDFから1ページずつJPGに変換（Adobe Acrobat／Macプレビュー／`pdftoppm` 等）
   - `pdftoppm` の例: `pdftoppm -jpeg -r 240 -jpegopt quality=85 input.pdf images/heijitsu-kudari`
     （`-r 240` が解像度dpi、出力後にページ番号でリネームして命名規則に合わせる）
3. 書き出したJPGを `images/` にリネームして配置

### アクセシビリティ・操作性メモ

- `<img>` に `alt` 属性を付与済みです（スクリーンリーダー対応の最低限）。
- スマホは `viewport` を `user-scalable` 制限なしにしているので、ピンチズームも併用できます。
- 各画像カードに「別タブで開く」リンクがあり、ブラウザの画像ビューアで
  ネイティブに拡大・保存できます。

## 印刷用PDFについて

- 1本の `pdf/kojak-timetable.pdf`（路線図＋時刻表 全15ページ）を全ページ共通で使い、
  各時刻表ページの「PDFを表示」ボタンは `#page=◯` で該当ページに自動ジャンプします。
- 実際に結合したPDFのページ番号が想定（下表）とズレた場合は、各HTMLファイル内の
  `href="pdf/kojak-timetable.pdf#page=◯"` の数字を実際のページ番号に合わせて
  書き換えてください。

  | ページ | 内容 |
  |---|---|
  | 1 | 路線図 |
  | 2-4 | 平日 下り |
  | 5-7 | 平日 上り |
  | 8-9 | 土曜日 下り |
  | 10-11 | 土曜日 上り |
  | 12-13 | 日祭日 下り |
  | 14-15 | 日祭日 上り |

## 新規リポジトリ作成時の注意点

1. **公開範囲（Public/Private）**
   GitHub PagesでWeb公開するには基本的に **Public** リポジトリである必要があります
   （GitHub Free プランの場合）。「不特定多数に見られたくない情報」は載せない前提で
   運用してください（本サイトは公開されている時刻表情報なので通常問題ありません）。

2. **ライセンス表記**
   `LICENSE.md` を同梱していますが、GitHubの「Choose a license」機能で
   一般的なOSSライセンス（MIT等）を選んでしまうと「改変・再配布自由」に
   なってしまうため、**選ばない（=事実上の All Rights Reserved）** か、
   `LICENSE.md` の記載を優先する運用にしてください。

3. **ファイルサイズ**
   GitHubは1ファイル100MBまで、リポジトリ全体はソフト上限1GB程度が目安です。
   上記の推奨解像度（JPG 1枚1〜2MB以下）であれば、14枚のJPG＋PDF1本でも
   合計10〜20MB程度に収まり、Git LFSなどの特別な設定は不要です。

4. **GitHub Pages の設定**
   リポジトリ作成後、`Settings > Pages` で
   `Deploy from a branch` → `main` ブランチ / `/(root)` を選択して公開してください。
   公開URLは `https://<ユーザー名>.github.io/<リポジトリ名>/` になります。

5. **画像・PDFの著作権保護について（重要）**
   HTMLの `download` 属性やコピーガードは、ブラウザの標準機能を超えて
   コピー自体を技術的に禁止するものではありません（右クリック禁止などは
   容易に回避されます）。「改変・書き込み禁止」を実効性のあるものにするには、
   - JPG/PDFの隅に小さく「© 作成者名／転載・改変禁止」などの透かし・
     クレジットを**画像自体に焼き込んでおく**
   - `LICENSE.md` や各ページの注意書きで利用条件を明記する（本サイトは対応済み）
   の組み合わせが現実的です。技術的な閲覧専用化（改変不可のPDF権限設定）を
   併用したい場合は、PDF書き出し時に「編集・注釈を制限」するパスワード設定も
   可能です（Acrobat等の「アクセス許可パスワード」機能）。

6. **404ページ／トップURL**
   `index.html` がトップページとして機能するので、`https://.../<リポジトリ名>/`
   にアクセスすればそのまま表示されます。個別ページへの直接リンクも
   `https://.../<リポジトリ名>/heijitsu-kudari.html` のように共有可能です。

7. **.gitignore**
   OS由来のゴミファイル対策に、最低限下記を `.gitignore` に入れておくと安全です。
   ```
   .DS_Store
   Thumbs.db
   ```

## 動作確認のしかた（ローカル）

`assets/nav.js` は `<script src>` 読込のみでfetch通信をしていないため、
`index.html` をブラウザでダブルクリックして開くだけ（`file://`）でも動作します。
GitHub Pages公開前のローカル確認に便利です。

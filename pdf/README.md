# pdf フォルダ

Excelの全シート（路線図1ページ＋時刻表14ページ＝計15ページ）を
1つのPDFに結合し、`kojak-timetable.pdf` という名前でここに置いてください。

ページ順は images と揃えてあります（各HTMLの「PDFを表示」ボタンは
`#page=N` でこのページ番号にジャンプします）。

1. 路線図
2-4. 平日 下り
5-7. 平日 上り
8-9. 土曜日 下り
10-11. 土曜日 上り
12-13. 日祭日 下り
14-15. 日祭日 上り

※ 実際のページ番号がズレる場合は、各HTML内の `#page=` の数値を
   合わせて修正してください。
